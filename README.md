# iglesianuestrohogar.cl

Sitio de **Iglesia Nuestro Hogar** (Chillán) — *Hay un lugar para ti*.

Diseño basado en el sistema de diseño de Airbnb del catálogo DesignMD (lienzo blanco,
fotografía protagonista, un solo color de marca — el celeste del logo — y formas suaves).

## Estructura
- `index.html` — página completa
- `css/styles.css` — estilos (variables de color al inicio)
- `js/script.js` — interacciones. **Para publicar eventos, edita la lista `EVENTOS` al inicio.**
- `assets/web/` — fotos optimizadas (WebP) y logos que usa el sitio
- `assets/img/` — fotos originales (no se usan directamente)
